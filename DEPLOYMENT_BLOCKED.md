# ⚠️ Деплой заблокирован - Merge конфликты

**Дата:** 2025-01-27  
**Статус:** 🔴 Требуется разрешение конфликтов

---

## Проблема

Обнаружены merge конфликты в нескольких файлах, которые блокируют сборку проекта.

### Оставшиеся проблемные файлы:
- `src/app/api/telegram/features/route.ts`
- `src/app/api/telegram/web3/route.ts`
- `src/app/api/clubs/leave/route.ts`
- `src/app/api/health/route.ts`
- `src/app/api/tracks/upload/route.ts`

---

## Решение

### Вариант 1: Использовать git (рекомендуется)

```bash
# Отменить текущий merge
git merge --abort

# Затем правильно разрешить конфликты
git pull origin main  # или ваша ветка
# Разрешить конфликты вручную
# Закоммитить изменения
```

### Вариант 2: Принять одну из версий

```bash
# Принять нашу версию (HEAD)
git checkout --ours src/app/api/telegram/features/route.ts

# Или принять их версию
git checkout --theirs src/app/api/telegram/features/route.ts
```

### Вариант 3: Ручное исправление

1. Откройте проблемные файлы
2. Найдите маркеры `<<<<<<< HEAD`, `=======`, `>>>>>>>`
3. Выберите нужную версию кода
4. Удалите маркеры конфликтов
5. Сохраните файлы

---

```bash
# 1. Проверить сборку
```
