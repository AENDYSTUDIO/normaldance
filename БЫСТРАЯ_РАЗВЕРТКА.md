## 🌊 BRIDGE СИСТЕМА

### 🔄 **Как работает:**
```typescript
// Browser (OSS) → Bridge API → Commercial IP
fetch('/api/bridge/gravemorial')                // Frontend
  .then(res => res.json())                    // Bridge middleware
  .then(data => callPrivateAPI(data))         // Secure API call
  .then(memorial => showMemorial(memorial))  // User sees result
```

### 🛡️ **Безопасность Bridge:**
- ✅ JWT токены (15 минут)
- ✅ HMAC-SHA256 подписи  
- ✅ Rate limiting (10 req/min)
