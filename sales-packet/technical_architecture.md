# Техническая архитектура проекта NORMALDANCE 0.4.0

## Обзор архитектуры

NORMALDANCE 0.4.0 представляет собой production-ready Web3-платформу с мобильным приложением, AI-системой и мульти-чейн поддержкой. Архитектура объединяет блокчейн-технологии Solana, TON и 5 других сетей с передовыми веб-технологиями, обеспечивая масштабируемость, безопасность и удобство использования корпоративного уровня.

**Обновление Ноябрь 2025:** Добавлены мобильное приложение, enterprise AI, мульти-чейн мосты и система ZK-приватности.

## Компоненты системы

### 1. Frontend
- **Next.js 15** - основной фреймворк для фронтенда
- **TypeScript** - строгая типизация
- **React** - компонентная архитектура
- **Invisible Wallet** - биометрическая аутентификация
- **Socket.IO** - реал-тайм коммуникации

### 2. Backend
- **Кастомный сервер** (server.ts) с поддержкой Socket.IO
- **API маршруты** для взаимодействия с блокчейном
- **Валидация и аутентификация** запросов
- **Кэширование** для производительности

### 3. Блокчейн-слои
- **Solana Programs**:
  - NDT Program: Управление токенами с дефляционной моделью
  - TrackNFT Program: Создание и управление музыкальными NFT
  - Staking Program: Стейкинг и вознаграждения
- **TON интеграция**: Поддержка TON кошельков и токенов
- **Fixed Program IDs**: Защита от изменений в смарт-контрактах

### 4. Хранилище данных
- **Prisma ORM**: Глобальный инстанс для работы с БД
- **IPFS**: Децентрализованное хранение медиа-файлов
- **Шардинг**: Масштабируемость базы данных
- **Репликация**: Надежность хранения данных

## Ключевые архитектурные решения

### 1. Глобальный инстанс Prisma
Вместо создания новых инстансов Prisma для каждого запроса, используется один глобальный инстанс в `src/lib/db.ts` для оптимизации подключений к базе данных.

### 2. Мульти-шлюзовая IPFS репликация
Используется мульти-шлюзовая система в `src/lib/ipfs-enhanced.ts` и `src/lib/ipfs-helia-complete.ts` для обеспечения надежного доступа к данным.

### 3. Дефляционная модель токенов
Все транзакции проходят через `DeflationaryModel` с 2% burn, что создает дефляционное давление на токены и потенциально увеличивает их стоимость.

### 4. Биометрическая аутентификация
Реализована "невидимая" система кошелька с биометрической аутентификацией для улучшения пользовательского опыта.

### 5. Multi-chain архитектура
Поддержка как Solana, так и TON блокчейнов с фиксированными Program ID для стабильности.

## Технические спецификации

### Backend
- **Язык**: TypeScript
- **Фреймворк**: Next.js 15 (с кастомным server.ts)
- **Сервер**: Node.js с tsx
- **WebSocket**: Socket.IO по пути `/api/socketio`
- **ORM**: Prisma (глобальный инстанс)

### Frontend
- **Фреймворк**: Next.js 15
- **Язык**: TypeScript
- **Компилятор**: Babel
- **Стили**: Tailwind CSS или другая CSS-библиотека

### Блокчейн
- **Solana**: Rust программы (в папке programs/)
- **TON**: Интеграция через SDK
- **Program IDs**: Фиксированные, настраиваются через env переменные

### Хранилище
- **База данных**: PostgreSQL/MySQL через Prisma
- **Файлы**: IPFS с мульти-шлюзовой репликацией
- **Кэширование**: Redis или встроенные механизмы

### Инфраструктура
- **Контейнеризация**: Docker
- **Оркестрация**: Kubernetes (опционально)
- **IaC**: Pulumi
- **Мониторинг**: Prometheus, AlertManager
