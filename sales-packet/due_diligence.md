# Материалы для проверки покупателями (Due Diligence) проекта NORMALDANCE

## Обзор материалов due diligence

Этот документ предоставляет полную информацию для потенциальных покупателей проекта NORMALDANCE, позволяя им провести всестороннюю проверку перед приобретением. Все материалы организованы по ключевым категориям для удобства анализа.

## 1. Техническая документация

### 1.1 Архитектура системы
- **MVP_ARCHITECTURE.md**: Полное описание архитектуры проекта
- **technical_architecture.md**: Технические детали архитектуры
- **src/lib/db.ts**: Глобальный Prisma инстанс (критическая компонента)
- **server.ts**: Кастомный сервер с Socket.IO
- **programs/**: Solana программы (NDT, TrackNFT, Staking)

### 1.2 Ключевые технические решения
- **unique_features.md**: Уникальные архитектурные решения
- **src/lib/deflationary-model.ts**: Реализация 2% burn модели
- **src/components/wallet/invisible-wallet-adapter.tsx**: Биометрическая аутентификация
- **src/lib/ipfs-enhanced.ts и src/lib/ipfs-helia-complete.ts**: IPFS репликация
- **src/lib/db/sharding.ts**: Шардинг базы данных

### 1.3 Интеграции
- **TON интеграция**: Поддержка TON и $50,000 грант
- **Multi-chain**: Поддержка Solana и TON с фиксированными Program ID
- **IPFS**: Мульти-шлюзовая система хранения
- **Socket.IO**: Реал-тайм коммуникации
