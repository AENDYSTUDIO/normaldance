# Стратегическая дорожная карта проекта NORMALDANCE

## Обзор дорожной карты

Дорожная карта NORMALDANCE представляет собой многоэтапный план развития проекта, начиная с завершенного MVP и заканчивая глобальным масштабированием платформы. Каждый этап включает ключевые вехи, технические улучшения и стратегические инициативы.

## Этап 1: Завершенный MVP (Уже реализовано)

### Статус: ЗАВЕРШЕН
### Время: Q1-Q3 2024

#### Ключевые достижения:
- **Архитектурная основа**: Полностью реализована MVP-архитектура (MVP_ARCHITECTURE.md)
- **Solana программы**: Созданы все основные программы (NDT, TrackNFT, Staking)
- **Frontend фреймворк**: Next.js 15 с кастомным сервером
- **Биометрическая аутентификация**: Invisible Wallet с биометрической системой
- **IPFS интеграция**: Мульти-шлюзовая репликация для хранения данных
- **Database**: Глобальный Prisma инстанс для оптимизации подключений

#### Технические компоненты:
- [x] Кастомный сервер с Socket.IO (`/api/socketio`)
- [x] Solana программы для NDT, TrackNFT и Staking
- [x] Интеграция с TON и грант на $50,000
- [x] IPFS-репликация через мульти-шлюзы
- [x] Дефляционная модель (2% burn) для токенов
- [x] Invisible Wallet с биометрической аутентификацией
