# Структура проекта NORMALDANCE

## Описание проекта

Проект NORMALDANCE представляет собой комплексную платформу с интеграцией блокчейна, Web3 технологий и мобильных приложений. Включает в себя NFT-маркетплейс, стейкинг интерфейс, инфраструктуру для управления активами и систему безопасности.

## Основные директории

### `/src` - Исходный код приложения

Основная директория с исходным кодом React/Next.js приложения. Содержит компоненты, страницы, библиотеки и сервисы.

### `/contracts` - Контракты смарт-контрактов

Директория с контрактами для блокчейна, включая Solidity и Rust реализации.

### `/mobile-app` - Мобильное приложение

Исходный код мобильного приложения, разработанного с использованием Expo.

### `/scripts` - Скрипты автоматизации

Набор скриптов для деплоя, настройки окружения, безопасности и других задач.

### `/docs` - Документация

Вся документация проекта, включая технические спецификации, руководства разработчиков и архитектурные диаграммы.

### `/config` - Конфигурационные файлы

Файлы конфигурации для различных компонентов системы.

### `/prisma` - Конфигурация базы данных

Файлы Prisma для работы с базой данных.

### `/grants` - Информация о грантах

Документы и данные по грантовым программам, включая TON Grant.

### `/k8s` - Kubernetes конфигурации

Конфигурационные файлы для развертывания в Kubernetes.

### `/helm` - Helm чарты

Helm чарты для управления Kubernetes приложениями.

### `/docker` - Docker конфигурации

Docker файлы и конфигурации для контейнеризации приложения.

### `/nginx` - Конфигурации Nginx

Конфигурационные файлы для Nginx веб-сервера.

### `/backups` - Резервные копии

Скрипты и данные для резервного копирования.

### `/monitoring` - Мониторинг

Инструменты и скрипты для мониторинга состояния системы.

### `/security` - Безопасность

Скрипты и конфигурации для обеспечения безопасности.

### `/legal` - Юридические документы

Юридические документы и соглашения.

### `/public` - Публичные ресурсы

Публичные файлы, такие как изображения, стили и другие ресурсы.

### `/tests` - Тесты

Тестовые файлы для различных компонентов приложения.

### `/examples` - Примеры кода

Примеры использования различных компонентов и API.

### `/reports` - Отчеты

Аналитические отчеты и данные.

### `/policy` - Политики

Политики безопасности и конфиденциальности.

### `/types` - Типы TypeScript

Файлы определений типов для TypeScript.

### `/_archive-docs` - Архивная документация

Архивированная документация и старые руководства.

### `/.github` - GitHub конфигурации

Конфигурационные файлы GitHub Actions и другие репозиторные настройки.

### `/.husky` - Хуки Git

Хуки pre-commit для автоматической проверки кода.

### `/AE` - AE (возможно, часть архитектуры)

Директория, связанная с архитектурой или компонентами системы.

### `/MVP` - Минимально жизнеспособный продукт

Код и документация для MVP версии проекта.

### `/ND` - Название проекта

Возможно, содержит дополнительные ресурсы или компоненты проекта.

## Ключевые файлы

### `.env.example` - Пример конфигурационного файла

Шаблон для файлов окружения.

### `.gitignore` - Игнорируемые файлы Git

Определяет файлы и директории, которые не должны быть добавлены в Git.

### `Dockerfile` - Docker файл

Файл для создания Docker образа приложения.

### `package.json` - Зависимости проекта

Файл с описанием зависимостей и скриптами проекта.

### `README.md` - Главный файл README

Основное описание проекта и инструкции по запуску.

### `ARCHITECTURAL_DIAGRAM.md` - Архитектурная диаграмма

Описание архитектуры проекта.

### `CONTRIBUTING.md` - Руководство по внесению изменений

Инструкции для разработчиков по участию в проекте.

### `CHANGELOG.md` - Журнал изменений

История изменений в проекте.

## Специфические компоненты

### Интеграция с блокчейном

- Смарт-контракты в `/contracts`
- Интеграция с Web3 и биометрической аутентификацией
- Модель дефляции токенов в `src/lib/deflationary-model.ts`

### Мобильное приложение

- Разработка с использованием Expo в `/mobile-app`
- Интеграция с Telegram Mini Apps

### Система безопасности

- Мониторинг безопасности в `/monitoring`
- Скрипты безопасности в `/scripts/security-*`
- Интеграция с Chainalysis и Sumsub

### CI/CD и деплой

- Скрипты деплоя в `/scripts/deploy-*`
- Конфигурации в `/docker`, `/k8s`, `/helm`
- GitHub Actions в `/.github`

### База данных

- Конфигурация Prisma в `/prisma`
- SQL скрипты в `/db`

### Аналитика и мониторинг

- Мониторинг в `/monitoring`
- Скрипты метрик в `/scripts/metrics.sh`
