## 🔧 ЕСЛИ ПРОБЛЕМЫ

### 🚨 **Bridge не работает?**
```bash
# Диагностика bridge:
curl -X POST https://app.normaldance.online/api/auth/bridge-token \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $BRIDGE_API_KEY" \
  -d '{"clientId":"normaldance-frontend","service":"test","scope":["grav"]}'

# Проверить переменные окружения:
echo $BRIDGE_CLIENT_ID
echo $BRIDGE_API_KEY
```

### 🚨 **G.Rave не работает?**
```bash
# Проверить контракт:
npx hardhat verify --network polygon $CONTRACT_ADDRESS

# Проверить домен:
curl -I https://grave.app.normaldance.online
```
