# Обновления модулей безопасности NORMALDANCE v0.5.0

## Обзор изменений

В этой версии были внесены значительные улучшения в архитектуру модулей безопасности для устранения дублирования кода и повышения консистентности. Все функции безопасности теперь доступны через единую точку входа `@/lib/security`.

## Основные изменения

### 1. Устранение дублирования кода

Ранее функции санитизации и валидации были разбросаны по нескольким файлам:
- `src/lib/security/input-sanitizer.ts`
- `src/lib/security/input-validator.ts`
- `src/lib/security/xss-csrf.ts`
- `src/lib/security/sanitize.ts`

Теперь все функции объединены и доступны через основную точку входа:
```typescript
import { escapeHTML, stripDangerousHtml, sanitizeURL } from '@/lib/security';
```

### 2. Депрекейт устаревших API

Следующие модули помечены как устаревшие и будут удалены в v2.0.0:
- `src/lib/security/input-sanitizer.ts`
- `src/lib/security/input-validator.ts`

Все функции из этих модулей теперь доступны через `@/lib/security` с теми же именами.

### 3. Улучшенная типизация и документация

Все функции безопасности теперь имеют четкую типизацию и документацию JSDoc.

## Миграция

### Обновление импортов

Вместо:
```typescript
import { sanitizeHTML } from "@/lib/security/input-sanitizer";
import { InputValidator } from "@/lib/security/input-validator";
```

Используйте:
```typescript
import { escapeHTML, stripDangerousHtml } from "@/lib/security";
```

### Замена функций

| Устаревшая функция | Новая функция |
|-------------------|---------------|
| `sanitizeHTML` | `escapeHTML` |
| `InputValidator.sanitizeHtml` | `escapeHTML` |
| `InputValidator.sanitizeSQL` | `sanitizeSQL` (по-прежнему доступна, но не рекомендуется) |

## Новые функции

### 1. Унифицированные санитайзеры
Все функции санитизации теперь следуют единой архитектуре и стандартам.

### 2. Улучшенная обработка логов
Добавлена новая функция `sanitizeLog` для безопасной обработки логов.

### 3. Централизованное управление конфигурацией безопасности
Все настройки безопасности теперь управляются через централизованный `SecurityManager`.

## Тестирование

Все изменения покрыты тестами. Исправлены противоречивые тесты для функций экранирования.

## Безопасность

Эти изменения повышают общую безопасность приложения за счет:
1. Устранения дублирования кода, которое могло привести к несогласованному поведению
2. Централизации функций безопасности для более легкого аудита
3. Улучшенной документации и типизации

## Известные проблемы

Некоторые тесты в предыдущей версии содержали противоречивые ожидания. Эти тесты были исправлены в новой версии.
